# ADK Developer Guides

This directory is new. It mirrors the `docs/guides/` tree in
[google/adk-python](https://github.com/google/adk-python/tree/main/docs/guides),
which holds one guide per feature for contributors reading the source. The
user-facing documentation for ADK lives at [adk.dev](https://adk.dev/), whose
source is [google/adk-docs](https://github.com/google/adk-docs); nothing here
replaces it.
