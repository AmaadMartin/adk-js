# ADK Developer Guides

This directory contains specific developer guides for the ADK TypeScript
implementation, mirroring the `docs/guides/` tree in
[google/adk-python](https://github.com/google/adk-python/tree/main/docs/guides),
one directory per topic and one guide per feature. For the official ADK
documentation, visit [adk.dev](https://adk.dev/).

## Index

### Evaluation

- [Pre-built user personas](evaluation/pre_built_personas/index.md) - The three
  personas ADK ships for the user simulator, the behaviors they are composed
  from, and how to register your own over a default.
- [User simulator personas](evaluation/user_simulator_personas/index.md) - What
  a persona and a behavior are, and the registry an eval run resolves a persona
  id through.
