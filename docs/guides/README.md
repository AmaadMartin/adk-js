# ADK Developer Guides

This directory contains specific developer guides for the ADK TypeScript implementation. It mirrors the `docs/guides/` tree in [google/adk-python](https://github.com/google/adk-python). For the official ADK documentation, visit [adk.dev](https://adk.dev/).
