# ADK Developer Guides

This directory contains developer guides for the ADK TypeScript implementation.
For the official ADK documentation, visit [adk.dev](https://adk.dev/).

The layout mirrors the guides in
[adk-python](https://github.com/google/adk-python/tree/main/docs/guides): one
directory per topic, one guide per feature.
