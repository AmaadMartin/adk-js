# ADK Developer Guides

This directory holds developer guides for the ADK TypeScript implementation. It
mirrors the `docs/guides/` tree in
[google/adk-python](https://github.com/google/adk-python/tree/main/docs/guides):
one directory per topic, one guide per feature. For the official ADK
documentation, visit [adk.dev](https://adk.dev/).

## Index

### Evaluation

- [Eval config](evaluation/eval_config/index.md) - Reading a `test_config.json`: the metrics to score, the code behind a custom metric, the user simulator, and the live model timeout.
