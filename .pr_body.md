This pull request implements the `BigQueryToolset` from `adk-python` into `adk-js`, providing TypeScript/JavaScript agents with powerful tools to interact with BigQuery data and metadata, execute queries, perform forecasting, analyze contribution, detect anomalies, leverage natural language semantic search via Dataplex, and use BigQuery AI/ML capabilities.

Problem: `adk-js` lacked the ability to natively interact with BigQuery datasets, execute queries, or run advanced ML/AI functions like ARIMA_PLUS forecasting, contribution analysis, and semantic catalog search, which were already supported in `adk-python`.

Solution:

- Ported `BigQueryToolset` to JavaScript/TypeScript under `core/src/tools/bigquery/`.
- Implemented core tools:
  - `metadata_tools`: `list_dataset_ids`, `get_dataset_info`, `list_table_ids`, `get_table_info`, `get_job_info`.
  - `query_tools`: `execute_sql`, `forecast` (using `AI.FORECAST`), `analyze_contribution` (using `ML.CREATE_MODEL` and `ML.GET_INSIGHTS`), `detect_anomalies` (ARIMA_PLUS).
  - `data_insights_tool`: `ask_data_insights` for natural language querying on BigQuery tables.
  - `search_tool`: `search_catalog` for semantic search across BigQuery via Dataplex.
  - `bigquery_skill`: Pre-packaged BigQuery AI/ML skill.
- Achieved 100% statement, branch, function, and line coverage for all BigQuery components with extensive unit tests under `core/test/tools/bigquery/`.
- Cleaned up lint issues and verified building and checking successfully.
