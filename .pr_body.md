**Problem**: The ADK lacked a way to easily interact with BigQuery data natively in Node.js agents, missing parity with the Python ADK.

**Solution**: This PR implements the `BigQueryToolset` and its associated standalone tools (`execute_sql`, `get_dataset_info`, `list_dataset_ids`, `get_table_info`, `list_table_ids`, `get_job_info`). It strictly enforces `WriteMode` behaviors (including session awareness for protected mode schema modifications). Extensive unit tests assert default behaviors, query filtering, and failure scenarios. It leverages standard SDK dependencies to simplify types.
