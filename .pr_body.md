Problem:
The skills registry is implemented in `adk-python` but was missing in the TypeScript (`adk-js`) implementation, which is needed to support fetching and listing skills from GCP Skill Registry in JS/TS agents.

Solution:

- Ported `SkillRegistry` abstract class to `adk-js` ([skill_registry.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/skills/skill_registry.ts)).
- Implemented `GCPSkillRegistry` class using the GCP Skill Registry REST API with fetch and Vertex AI scopes ([gcp_skill_registry.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/integrations/skill_registry/gcp_skill_registry.ts)).
- Created `loadSkillFromZipBytes` helper in the skill loader, allowing loading skill packages directly from raw zip buffer bytes, handling Zip-Slip protection, metadata validation, resource unpacking, and frontmatter parsing ([loader.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/skills/loader.ts)).
- Implemented `SearchSkillsTool` to search and discover remote skills from the registry ([search_skills_tool.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/tools/skill/search_skills_tool.ts)).
- Integrated `GCPSkillRegistry` with existing skill tools (`LoadSkillTool`, `LoadSkillResourceTool`, `RunSkillScriptTool`), allowing them to fetch skills dynamically from the registry if they aren't available locally ([load_skill_tool.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/tools/skill/load_skill_tool.ts), [load_skill_resource_tool.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/tools/skill/load_skill_resource_tool.ts), [run_skill_script_tool.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/tools/skill/run_skill_script_tool.ts)).
- Fixed a bug in `LoadSkillResourceTool.processLlmRequest` where binary resource files from registry-fetched skills were not injected into the conversation. It now correctly calls the asynchronous `getOrFetchSkill` method to retrieve cached remote skills.
- Implemented a turn-scoped cache with eviction logic in `SkillToolset` to cache registry-fetched skills during an execution turn ([skill_toolset.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/tools/skill/skill_toolset.ts)).
- Exported all new modules from the core public entry points ([index.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/index.ts), [common.ts](file:///usr/local/google/home/amaadmartin/Workspace/Agentspaces/feat-implement-skills-registry-1/adk-js/core/src/common.ts)).
