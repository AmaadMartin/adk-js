# Pull Request Description

## Description of Changes

This PR introduces the **Skills Registry** integration into `adk-js`, bringing it to strict architectural and functional parity with `adk-python`.

### Key Capabilities Implemented:

1. **Core Interface (`SkillRegistry`)**: Defined the explicit contract for skill fetching (`getSkill`) and discovery (`searchSkills`).
2. **GCP Vertex AI Integration (`GCPSkillRegistry`)**: Robust remote skill retrieval via Vertex AI internal endpoints (`skills.get` and `skills.retrieve`), parsing zipped in-memory filesystems into fully actionable L3 skills (`SKILL.md`, references, assets, scripts).
3. **Dynamic Skills Search Tool (`SearchSkillsTool`)**: Enabled LLM agents to dynamically search remote skill catalogs when local skills are insufficient, automatically filtering out naming collisions.
4. **Enhanced Toolset (`SkillToolset`)**: Equipped with per-turn bounded invocation caching, transparent remote fallback, and automatic dynamic tool resolution.
