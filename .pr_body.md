**Problem:**
The `adk-js` repository lacked support for fetching and searching skills from the GCP Vertex AI Skill Registry, which was already supported in the Python implementation (`adk-python`).

**Solution:**
Implemented the skills registry capability in `adk-js` to match `adk-python`:

- **SkillRegistry Interface (`skill_registry.ts`)**: Defines the standard interface for fetching and searching skills from a registry.
- **GCPSkillRegistry (`gcp_skill_registry.ts`)**: GCP implementation of `SkillRegistry` that calls the Vertex AI Skill Registry API.
- **loadSkillFromZipBytes (`loader.ts`)**: Utility to parse and load skills directly from in-memory zip file bytes, including zip slip protection and validation.
- **Exports**: Exported the new capabilities at the package entrypoints (`index.ts` and `common.ts`).
